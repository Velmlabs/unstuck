# @velmlabs/unstuck-protocol

The wire protocol shared by the [Unstuck](https://unstuck.sh) engine, viewer and relays: screen frames, JSON-RPC messages and the end-to-end encryption format.

You usually don't install this directly: [`@velmlabs/unstuck`](https://www.npmjs.com/package/@velmlabs/unstuck) and `@velmlabs/unstuck-core` depend on it.
